## 3. 返回数据是空的

* 请求参数: 不带参数、默认 page/pageSize

   ```json
   {
       "code": 1,
       "msg": null,
       "data": {
           "total": 5,
           "records": [
               {},
               {},
               {},
               {},
               {}
           ]
       }
   }
   ```

* 5 个空数据, 但表里面有数据
  - 应该是 records 列表全部记录的 null 对象, 赋值给 records 的 List 有问题
  - 情况 1: mybatis 查询拿到了非 null 列表, 但是 List 的元素全部是 null
  - 情况 2: mybatis 正常查询, 但是在实体类 List 转 VOList 的时候出错
* 明显是情况 2 更可能, 于是去看 converter 
  - `sky-server/target/generated-sources/annotations/com.sky.convertor.OrderConverterImpl.toPageVO`

   ```java
    @Override
    public List<AdminOrderPageVO> toPageVOList(List<Orders> entities) {
        if ( entities == null ) {
            return null;
        }
   
        List<AdminOrderPageVO> list = new ArrayList<AdminOrderPageVO>( entities.size() );
        for ( Orders orders : entities ) {
            list.add( toPageVO( orders ) );
        }
   
        return list;
    }
      
       @Override
       public AdminOrderPageVO toPageVO(Orders entity) {
           if ( entity == null ) {
               return null;
           }
   
           AdminOrderPageVO adminOrderPageVO = new AdminOrderPageVO();
   
           return adminOrderPageVO;
       }
   ```

  - toPageVO 竟然没有生成各个 set
  - 但有可能是直接 `return null` 了, 否则列表不应该全是 null 元素
  - 而且我 `mvn clean` 过后重新启动还是同样的 converter 代码
  - 哦哦哦, 对比 Orders、AdminOrderPageVO, 发现没有 set 字段的原因是我没给 VO 补上 @Data
    * 并且我没忽略目标对象的部分字段
    * `Unmapped target property: "orderDetailList"`
    * 由于前端展示用不到、所以我这里直接注释掉 vo 的部分字段
* 继续查询测试
  - 竟然正常查询到数据了
  - 再看 target 的 orderConverterImpl, 已经有了各个 set
  - 忘了, null 会直接在 json 展示为 null, 而空对象( 创建对象没给字段赋值 )是 `{}` 
  - 所以这里的根因是 target 对象没有设置 @Data / @Setter 导致 converter 实现类写不出 set, 从而出现空对象

  

## 4. 我的参数检验注解没有拦截空的 page/pageSize

* 只给 DTO 的字段补了注解, 但是 Controller 端点的 DTO 参数也需要补上 `@Valid`
  - 然而又不对

   ```text
   2026-08-17 10:19:08.479 ERROR 30400 --- [nio-8080-exec-2] com.sky.handler.GlobalExceptionHandler   : 未知系统异常
   
   org.springframework.validation.BindException: org.springframework.validation.BeanPropertyBindingResult: 1 errors
   Field error in object 'adminOrderPageQueryDTO' on field 'page': rejected value [null]; codes [NotNull.adminOrderPageQueryDTO.page,NotNull.page,NotNull.java.lang.Integer,NotNull]; arguments [org.springframework.context.support.DefaultMessageSourceResolvable: codes [adminOrderPageQueryDTO.page,page]; arguments []; default message [page]]; default message [起始页码不能为空]
   ```

* 全局异常处理器没有处理 `@Valid` 抛出的异常 `BindException`
  - 先捕获 BindException 看看
  - 确实可以
  - 后来发现 MethodArgumentNotValidException 是它的子类, 于是跟已有的方法合并 => 完整的 `捕获参数检验异常`
* 不过看来 DTO 设置的参数默认值会起作用
  - 只要 ApiFox 不传这个参数( page/pageSize ), 就可以用默认值
  - 但是只要传了参数( 就算没赋值 )就会覆盖掉我的默认值

## ApiFox 上传文件时后端报错 json 异常

1. 问题现象
    * POST `/admin/files/dish`
    * 我用 ApiFox 对着这个端点传入 form-date → 类型file, 参数值1个文件, 参数名 `file`
    * 但是后端输出异常

        ```text
        com.alibaba.fastjson.JSONException: write javaBean error, fastjson version 1.2.76, class org.springframework.web.multipart.support.StandardMultipartHttpServletRequest$StandardMultipartFile, fieldName : 0, write javaBean error, fastjson version 1.2.76, class org.springframework.web.multipart.MultipartFileResource, fieldName : resource
        ...
        Caused by: java.io.FileNotFoundException: MultipartFile resource [file] cannot be resolved to absolute file path
        ...
        ```

2. 相关代码

    ```java
    @PostMapping( "/dish" )
    @ApiOperation( value = "上传菜品图片" )
    @LogOperation( description = "上传菜品图片", operationType = OperationType.INSERT )
    public Result< String > uploadDishImage(
            @NotNull( message = "上传的图片不能为空" )
            MultipartFile file
    ){
        Long operatorId = BaseContext.getCurrentId();
        log.info( "id = {} 的管理员上传菜品图片: {}", operatorId, file.getName() );
        String url = fileService.upload( file, FileConstant.BusinessDir.DISH );
        return Result.success( url );
    }
    ```

3. AI 分析是 json 序列化出错
    * 并且直接定位到 aop 给方法参数做序列化的位置
    * 发现是文件等等类型不支持序列化, 就会报错
    * 于是把这些不支持序列化的类型过滤掉, 并且序列化补充 try-catch + 输出日志, 避免 aop 打断业务流程

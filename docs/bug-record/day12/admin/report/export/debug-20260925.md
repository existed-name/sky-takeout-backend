## sql 对 decimal 求和报错绑定失败

1. 问题现象
    * 测试导出数据表格, 报错绑定失败

        ```text
        org.apache.ibatis.binding.BindingException: 
        Mapper method 'com.sky.mapper.OrderMapper.sumAmountByStatusAndDateRange' has an unsupported return type: 
        class java.math.BigDecimal
        ```

    * 异常发生在 `com.sky.mapper.OrderMapper.sumAmountByStatusAndDateRange`
2. 看 sql

    ```xml
    <!--
    统计指定时间范围内的总营业额
    -->
    <delete id="sumAmountByStatusAndDateRange">
    SELECT sum( amount )
    FROM orders
    WHERE status = #{status}
    AND #{begin} &lt;= checkout_time
            AND checkout_time &lt; #{endExclusive}
    </delete>
    ```
   
3. 初步思考
    * 可能是对金额求和结果不匹配 BigDecimal
    * 但是 amount 确实是 decimal 类型
    * 而且之前的营业额统计接口也是 `sum( amount )`
    * 不过我看之前的 SQL 会给 `sum( amount )` 取别名 `turnover`, 然后包装成返回对象的字段
    * 然而我给这里补上别名依然会报错
    * 别名改为局部变量的名字也不行
4. 进一步发现
    * mapper 里面 xml 好像没写返回值类型, 而其他 xml 都有
    * 但是基本数据类型、包装类不需要指定 resultType
    * 但是还是尝试给它补上 resultType
    * 然而它冒红说不准, 而且编译后也报错
5. 余光一瞟
    * 怎么会是 delete...
    * 好吧 select + resultType 解决类型绑定问题

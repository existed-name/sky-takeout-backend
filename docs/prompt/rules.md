## 严格保持全局约束
1. **对话精简不废话**
2. 没有**明确的指令**不要修改代码、直接输出到当前对话
3. 不要阅读记忆
4. **需要补充信息就提醒我**
5. 输出内容的代码需要详细注释(如果有代码的话)
6. 保持**最佳实践**/大厂规范 + 结合现在的学习阶段, 给出**推荐操作**
    * 项目现有代码、结构未必是最佳实践，不要被它们限制了你的思考
7. **客观中立**
8. **没有同意**的情况下，不要写入记忆

---

* 使用操作: 
  - 在 Lingma 或者 Agent 对话框中用 `@rules.md` 引用这个文件
  - Lingma 可以在项目根目录单独建一个 `.lingma/rule`, 然后 `@rule` 打开规则文件夹，然后选取需要的规则文件

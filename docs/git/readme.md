## 文件说明

1. 这里是[git 命令文件夹](/docs/git)
2. 里面的各个 `.bat` 脚本是放在项目根目录的
    * 修改要添加的文件路径、message 
    * 然后跑脚本进行提交
3. `docs/git/notes` 存放的常用 git 命令笔记
    * 添加文件 `git add`
    * 查看状态 `git status`, 查看历史 `git log --oneline -5`...
    * rebase 操作
    * ...

## 个人感想

1. **用到了再学、边用边学**
    * 遇到了一个场景，于是问 AI / 查资料，找出对应的 git 命令
    * 用多了就熟悉了，不需要提前把所有命令大全背下来
2. 最简单的提交文件，或者修改上次的 commit，直接用 IDEA
    * 复杂一点的操作还是用命令行方便一点（虽然编译器也提供了可视化功能）
    * 但总的来说，某个场景见得多了、命令就熟悉，遇到新场景再问 AI、现学现用，实在不行还可以让 AI 跑命令行帮着操作 git

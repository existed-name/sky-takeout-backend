

## 微信用户登录


**接口地址**:`/user/users/login`


**请求方式**:`POST`


**请求数据类型**:`application/json`


**响应数据类型**:`*/*`


**接口描述**:


**请求示例**:


```javascript
{
  "code": "auth_code_example"
}
```


**请求参数**:


**请求参数**:


| 参数名称 | 参数说明 | 请求类型    | 是否必须 | 数据类型 | schema |
| -------- | -------- | ----- | -------- | -------- | ------ |
|userLoginDTO|C端用户登录请求参数|body|true|UserLoginDTO|UserLoginDTO|
|&emsp;&emsp;code|微信用户授权码||true|string||


**响应状态**:


| 状态码 | 说明 | schema |
| -------- | -------- | ----- | 
|200|OK|Result«UserLoginVO»|
|201|Created||
|401|Unauthorized||
|403|Forbidden||
|404|Not Found||


**响应参数**:


| 参数名称 | 参数说明 | 类型 | schema |
| -------- | -------- | ----- |----- | 
|code|业务码, 1成功，0和其它数字为失败|integer(int32)|integer(int32)|
|data|响应数据|UserLoginVO|UserLoginVO|
|&emsp;&emsp;id|用户主键ID|integer(int64)||
|&emsp;&emsp;openid|微信用户唯一标识openid|string||
|&emsp;&emsp;token|JWT令牌|string||
|msg|响应信息, 仅在异常时返回|string||


**响应示例**:
```javascript
{
	"code": 1,
	"data": {
		"id": 1,
		"openid": "o1234567890abcdef",
		"token": "eyJhbGciOiJIUzI1NiIs..."
	},
	"msg": "null"
}
```

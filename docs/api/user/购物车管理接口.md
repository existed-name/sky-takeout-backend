

## 用户查看购物车的所有内容


**接口地址**:`/user/shopping-carts`


**请求方式**:`GET`


**请求数据类型**:`application/x-www-form-urlencoded`


**响应数据类型**:`*/*`


**接口描述**:


**请求参数**:


**请求参数**:


暂无


**响应状态**:


| 状态码 | 说明 | schema |
| -------- | -------- | ----- | 
|200|OK|Result«ShoppingCartListVO»|
|401|Unauthorized||
|403|Forbidden||
|404|Not Found||


**响应参数**:


| 参数名称 | 参数说明 | 类型 | schema |
| -------- | -------- | ----- |----- | 
|code|业务码, 1成功，0和其它数字为失败|integer(int32)|integer(int32)|
|data|响应数据|ShoppingCartListVO|ShoppingCartListVO|
|&emsp;&emsp;items|购物车中包含的所有菜品、套餐信息|array|ShoppingCartItemVO|
|&emsp;&emsp;&emsp;&emsp;amount|套餐/菜品单价|number||
|&emsp;&emsp;&emsp;&emsp;dishFlavor|菜品口味|string||
|&emsp;&emsp;&emsp;&emsp;dishId|菜品 id|integer||
|&emsp;&emsp;&emsp;&emsp;id|数据库表 id|integer||
|&emsp;&emsp;&emsp;&emsp;image|套餐/菜品图片路径|string||
|&emsp;&emsp;&emsp;&emsp;name|套餐/菜品名称|string||
|&emsp;&emsp;&emsp;&emsp;number|套餐/菜品数量|integer||
|&emsp;&emsp;&emsp;&emsp;setmealId|套餐 id|integer||
|&emsp;&emsp;totalAmount|购物车总金额|number||
|msg|响应信息, 仅在异常时返回|string||


**响应示例**:
```javascript
{
	"code": 1,
	"data": {
		"items": [
			{
				"amount": 88,
				"dishFlavor": "微辣",
				"dishId": 1,
				"id": 1,
				"image": "",
				"name": "超值双人套餐",
				"number": 1,
				"setmealId": 1
			}
		],
		"totalAmount": 128.5
	},
	"msg": "null"
}
```





## 购物车添加菜品-套餐


**接口地址**:`/user/shopping-carts`


**请求方式**:`POST`


**请求数据类型**:`application/json`


**响应数据类型**:`*/*`


**接口描述**:


**请求示例**:


```javascript
{
  "dishFlavor": "微辣",
  "dishId": 1,
  "setmealId": 1
}
```


**请求参数**:


**请求参数**:


| 参数名称 | 参数说明 | 请求类型    | 是否必须 | 数据类型 | schema |
| -------- | -------- | ----- | -------- | -------- | ------ |
|shoppingCartDTO|购物车添加请求 DTO|body|true|ShoppingCartDTO|ShoppingCartDTO|
|&emsp;&emsp;dishFlavor|菜品口味(如果添加菜品时选择了口味, 则该字段存在)||false|string||
|&emsp;&emsp;dishId|菜品id（添加菜品时必填）||false|integer(int64)||
|&emsp;&emsp;setmealId|套餐id（添加套餐时必填）||false|integer(int64)||


**响应状态**:


| 状态码 | 说明 | schema |
| -------- | -------- | ----- | 
|200|OK|Result«Void»|
|201|Created||
|401|Unauthorized||
|403|Forbidden||
|404|Not Found||


**响应参数**:


| 参数名称 | 参数说明 | 类型 | schema |
| -------- | -------- | ----- |----- | 
|code|业务码, 1成功，0和其它数字为失败|integer(int32)|integer(int32)|
|msg|响应信息, 仅在异常时返回|string||


**响应示例**:
```javascript
{
	"code": 1,
	"msg": "null"
}
```

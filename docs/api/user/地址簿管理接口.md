## 新增收货地址

**响应数据类型**:`*/*`


**接口描述**:


**请求示例**:


```javascript
{
  "cityCode": 110100,
  "cityName": "北京市",
  "consignee": "张三",
  "detail": "XX街道XX号",
  "districtCode": 110105,
  "districtName": "朝阳区",
  "isDefault": 1,
  "label": 1,
  "phone": 13800138000,
  "provinceCode": 110000,
  "provinceName": "北京市",
```

|&emsp;&emsp;isDefault|是否默认地址：0 否  1 是||false|integer(int32)||
|&emsp;&emsp;label|标签||false|string||
|&emsp;&emsp;phone|收货人手机号||true|string||
|&emsp;&emsp;provinceCode|省级区划编号||false|string||
|&emsp;&emsp;provinceName|省份名称||true|string||
|&emsp;&emsp;sex|性别：1 男 2 女||true|string||

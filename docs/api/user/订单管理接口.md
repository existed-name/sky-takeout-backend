

## 用户下单并返回订单必要数据


**接口地址**:`/user/orders`


**请求方式**:`POST`


**请求数据类型**:`application/json`


**响应数据类型**:`*/*`


**接口描述**:


**请求示例**:


```javascript
{
  "addressBookId": 1,
  "amount": 99.99,
  "deliveryStatus": 1,
  "estimatedDeliveryTime": "2024-01-01 12:00:00",
  "packAmount": 2,
  "payMethod": 1,
  "remark": "不要辣",
  "tablewareNumber": 2,
  "tablewareStatus": 1
}
```


**请求参数**:


**请求参数**:


| 参数名称 | 参数说明 | 请求类型    | 是否必须 | 数据类型 | schema |
| -------- | -------- | ----- | -------- | -------- | ------ |
|ordersSubmitDTO|用户提交订单数据传输对象 DTO|body|true|OrdersSubmitDTO|OrdersSubmitDTO|
|&emsp;&emsp;addressBookId|地址簿id||true|integer(int64)||
|&emsp;&emsp;amount|订单总金额||true|number||
|&emsp;&emsp;deliveryStatus|配送状态：1 立即送出  0 选择具体时间||true|integer(int32)||
|&emsp;&emsp;estimatedDeliveryTime|期望送达时间||false|string||
|&emsp;&emsp;packAmount|打包费||true|integer(int32)||
|&emsp;&emsp;payMethod|付款方式：1 微信支付  2 支付宝支付||true|integer(int32)||
|&emsp;&emsp;remark|订单备注||false|string||
|&emsp;&emsp;tablewareNumber|餐具数量||false|integer(int32)||
|&emsp;&emsp;tablewareStatus|餐具数量状态：1 按餐量提供  0 选择具体数量||true|integer(int32)||


**响应状态**:


| 状态码 | 说明 | schema |
| -------- | -------- | ----- | 
|200|OK|Result«OrderSubmitVO»|
|201|Created||
|401|Unauthorized||
|403|Forbidden||
|404|Not Found||


**响应参数**:


| 参数名称 | 参数说明 | 类型 | schema |
| -------- | -------- | ----- |----- | 
|code|业务码, 1成功，0和其它数字为失败|integer(int32)|integer(int32)|
|data|响应数据|OrderSubmitVO|OrderSubmitVO|
|&emsp;&emsp;id|订单id|integer(int64)||
|&emsp;&emsp;orderAmount|订单金额|number||
|&emsp;&emsp;orderNumber|订单号|string||
|&emsp;&emsp;orderTime|下单时间|string(date-time)||
|msg|响应信息, 仅在异常时返回|string||


**响应示例**:
```javascript
{
	"code": 1,
	"data": {
		"id": 1,
		"orderAmount": 99.99,
		"orderNumber": 202401011200000001,
		"orderTime": "2024-01-01 12:00:00"
	},
	"msg": "null"
}
```

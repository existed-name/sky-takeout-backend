

## 某天的运营数据一览


**接口地址**:`/admin/workspace/overview/data`


**请求方式**:`GET`


**请求数据类型**:`application/x-www-form-urlencoded`


**响应数据类型**:`*/*`


**接口描述**:


**请求参数**:


**请求参数**:


| 参数名称 | 参数说明 | 请求类型    | 是否必须 | 数据类型 | schema |
| -------- | -------- | ----- | -------- | -------- | ------ |
|date|date|query|true|string(date)||


**响应状态**:


| 状态码 | 说明 | schema |
| -------- | -------- | ----- | 
|200|OK|Result«DataOverviewVO»|
|401|Unauthorized||
|403|Forbidden||
|404|Not Found||


**响应参数**:


| 参数名称 | 参数说明 | 类型 | schema |
| -------- | -------- | ----- |----- | 
|code|业务码, 1成功，0和其它数字为失败|integer(int32)|integer(int32)|
|data|响应数据|DataOverviewVO|DataOverviewVO|
|&emsp;&emsp;newUsers|新增用户量|integer(int64)||
|&emsp;&emsp;orderCompletionRate|订单完成率 = 有效订单数 / 订单总数, 保留到小数点后 4 位, 由前端转为百分数|number(double)||
|&emsp;&emsp;turnover|营业额 = 有效订单金额总和|number||
|&emsp;&emsp;unitPrice|平均客单价 = 营业额 / 有效订单数量|number||
|&emsp;&emsp;validOrderCount|有效订单数|integer(int64)||
|msg|响应信息, 仅在异常时返回|string||


**响应示例**:
```javascript
{
	"code": 1,
	"data": {
		"newUsers": 18,
		"orderCompletionRate": 0.8222,
		"turnover": 1688,
		"unitPrice": 66.66,
		"validOrderCount": 88
	},
	"msg": "null"
}
```

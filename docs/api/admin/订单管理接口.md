

## 条件分页查询订单


**接口地址**:`/admin/orders`


**请求方式**:`GET`


**请求数据类型**:`application/x-www-form-urlencoded`


**响应数据类型**:`*/*`


**接口描述**:


**请求参数**:


**请求参数**:


| 参数名称 | 参数说明 | 请求类型    | 是否必须 | 数据类型 | schema |
| -------- | -------- | ----- | -------- | -------- | ------ |
|page|起始页码|query|true|integer(int32)||
|pageSize|每页记录数|query|true|integer(int32)||
|截止下单时间||query|false|string(date-time)||
|手机号||query|false|string||

|订单状态||query|false|integer(int32)||
|起始下单时间||query|false|string(date-time)||

|&emsp;&emsp;&emsp;&emsp;deliveryTime|送达时间|string||

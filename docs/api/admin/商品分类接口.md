

## 对分类进行条件分页查询


**接口地址**:`/admin/categories`


**请求方式**:`GET`


**请求数据类型**:`application/x-www-form-urlencoded`


**响应数据类型**:`*/*`


**接口描述**:


**请求参数**:


**请求参数**:


| 参数名称 | 参数说明 | 请求类型    | 是否必须 | 数据类型 | schema |
| -------- | -------- | ----- | -------- | -------- | ------ |
|page|起始页码|query|true|integer(int32)||
|pageSize|每页记录数|query|true|integer(int32)||
|name|分类名称|query|false|string||
|type|分类类型：1 菜品分类  2 套餐分类|query|false|integer(int32)||


**响应状态**:


| 状态码 | 说明 | schema |
| -------- | -------- | ----- | 
|200|OK|Result«PageResult«CategoryPageQueryItemVO»»|
|401|Unauthorized||
|403|Forbidden||
|404|Not Found||


**响应参数**:


| 参数名称 | 参数说明 | 类型 | schema |
| -------- | -------- | ----- |----- | 
|code|业务码, 1成功，0和其它数字为失败|integer(int32)|integer(int32)|
|data|响应数据|PageResult«CategoryPageQueryItemVO»|PageResult«CategoryPageQueryItemVO»|
|&emsp;&emsp;records|当前页数据 List 集合|array|CategoryPageQueryItemVO|
|&emsp;&emsp;&emsp;&emsp;createTime|创建时间|string||
|&emsp;&emsp;&emsp;&emsp;id|主键|integer||
|&emsp;&emsp;&emsp;&emsp;name|分类名称|string||
|&emsp;&emsp;&emsp;&emsp;sort|顺序序号|integer||
|&emsp;&emsp;&emsp;&emsp;type|类型：1 菜品分类 2 套餐分类|integer||
|&emsp;&emsp;total|分页前, 满足筛选条件的总记录数|integer(int64)||
|msg|响应信息, 仅在异常时返回|string||


**响应示例**:
```javascript
{
	"code": 1,
	"data": {
		"records": [
			{
				"createTime": "2026-09-27 15:21",
				"id": 1,
				"name": "川菜",
				"sort": 1,
				"type": 1
			}
		],
		"total": 100
	},
	"msg": "null"
}
```

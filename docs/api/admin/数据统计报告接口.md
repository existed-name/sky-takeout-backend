## 订单数据统计


**接口地址**:`/admin/report/order-statistics`


**请求方式**:`GET`


**请求数据类型**:`application/x-www-form-urlencoded`


**响应数据类型**:`*/*`


**接口描述**:


**请求参数**:


**请求参数**:


| 参数名称 | 参数说明 | 请求类型    | 是否必须 | 数据类型 | schema |
| -------- | -------- | ----- | -------- | -------- | ------ |
|begin|begin|query|true|string(date)||
|end|end|query|true|string(date)||


**响应状态**:


| 状态码 | 说明 | schema |
| -------- | -------- | ----- | 
|200|OK|Result«OrderReportVO»|
|401|Unauthorized||
|403|Forbidden||
|404|Not Found||


**响应参数**:


| 参数名称 | 参数说明 | 类型 | schema |
| -------- | -------- | ----- |----- | 
|code|业务码, 1成功，0和其它数字为失败|integer(int32)|integer(int32)|
|data|响应数据|OrderReportVO|OrderReportVO|
|&emsp;&emsp;orderCompletionRate|累计订单完成率|number(double)||
|&emsp;&emsp;orderCountList|每日订单数据项列表|array|OrderCountItemVO|
|&emsp;&emsp;&emsp;&emsp;count|当天的订单数量|integer||
|&emsp;&emsp;&emsp;&emsp;date|日期|string||
|&emsp;&emsp;totalOrderCount|累计订单总数|integer(int64)||
|&emsp;&emsp;validOrderCount|累计有效订单数|integer(int64)||
|&emsp;&emsp;validOrderCountList|每日有效订单数据项列表|array|OrderValidCountItemVO|
|&emsp;&emsp;&emsp;&emsp;count|当天的有效订单数量|integer||
|&emsp;&emsp;&emsp;&emsp;date|日期|string||
|msg|响应信息, 仅在异常时返回|string||


**响应示例**:
```javascript
{
	"code": 1,
	"data": {
		"orderCompletionRate": 0.8222,
		"orderCountList": "[\n  {\n    \"date\": \"2026-06-20\",\n    \"count\": 4\n  },\n  {\n    \"date\": \"2026-06-23\",\n    \"count\": 1\n  }\n]",

		"validOrderCount": 1388,
		"validOrderCountList": "[\n  {\n    \"date\": \"2026-06-20\",\n    \"count\": 2\n  }\n]"
	},
	"msg": "null"
```



## 条件分页查询员工


**接口地址**:`/admin/employees`


**请求方式**:`GET`


**请求数据类型**:`application/x-www-form-urlencoded`


**响应数据类型**:`*/*`


**接口描述**:


**请求参数**:


**请求参数**:


| 参数名称 | 参数说明 | 请求类型    | 是否必须 | 数据类型 | schema |
| -------- | -------- | ----- | -------- | -------- | ------ |
|page|起始页码|query|true|integer(int32)||
|pageSize|每页记录数|query|true|integer(int32)||
|name|员工姓名（模糊查询）|query|false|string||


**响应状态**:


| 状态码 | 说明 | schema |
| -------- | -------- | ----- | 
|200|OK|Result«PageResult«EmployeePageQueryItemVO»»|
|401|Unauthorized||
|403|Forbidden||
|404|Not Found||


**响应参数**:


| 参数名称 | 参数说明 | 类型 | schema |
| -------- | -------- | ----- |----- | 
|code|业务码, 1成功，0和其它数字为失败|integer(int32)|integer(int32)|
|data|响应数据|PageResult«EmployeePageQueryItemVO»|PageResult«EmployeePageQueryItemVO»|
|&emsp;&emsp;records|当前页数据 List 集合|array|EmployeePageQueryItemVO|
|&emsp;&emsp;&emsp;&emsp;id|员工表id|integer||
|&emsp;&emsp;&emsp;&emsp;name|员工姓名|string||
|&emsp;&emsp;&emsp;&emsp;phone|员工手机号|string||
|&emsp;&emsp;&emsp;&emsp;status|账号启用状态|integer||
|&emsp;&emsp;&emsp;&emsp;updateTime|更新时间|string||
|&emsp;&emsp;&emsp;&emsp;username|员工账号用户名(唯一)|string||
|&emsp;&emsp;total|分页前, 满足筛选条件的总记录数|integer(int64)||
|msg|响应信息, 仅在异常时返回|string||


**响应示例**:
```javascript
{
	"code": 1,
	"data": {
		"records": [
			{
				"id": 1,
				"name": "张三",
				"phone": 13800138000,
				"status": 1,
				"updateTime": "2026-09-27 08:13:06",
				"username": "admin"
			}
		],
		"total": 100
	},
	"msg": "null"
}
```

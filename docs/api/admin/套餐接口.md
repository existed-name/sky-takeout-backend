

## 条件分页查询套餐


**接口地址**:`/admin/setmeals`


**请求方式**:`GET`


**请求数据类型**:`application/x-www-form-urlencoded`


**响应数据类型**:`*/*`


**接口描述**:


**请求参数**:


**请求参数**:


| 参数名称 | 参数说明 | 请求类型    | 是否必须 | 数据类型 | schema |
| -------- | -------- | ----- | -------- | -------- | ------ |
|page|起始页码|query|true|integer(int32)||
|pageSize|每页记录数|query|true|integer(int32)||
|categoryId|所属的分类 id|query|false|integer(int32)||
|name|套餐名称（模糊查询）|query|false|string||
|status|起售状态 0表示停售 1表示起售|query|false|integer(int32)||


**响应状态**:


| 状态码 | 说明 | schema |
| -------- | -------- | ----- | 
|200|OK|Result«PageResult«SetmealPageQueryItemVO»»|
|401|Unauthorized||
|403|Forbidden||
|404|Not Found||


**响应参数**:


| 参数名称 | 参数说明 | 类型 | schema |
| -------- | -------- | ----- |----- | 
|code|业务码, 1成功，0和其它数字为失败|integer(int32)|integer(int32)|
|data|响应数据|PageResult«SetmealPageQueryItemVO»|PageResult«SetmealPageQueryItemVO»|
|&emsp;&emsp;records|当前页数据 List 集合|array|SetmealPageQueryItemVO|
|&emsp;&emsp;&emsp;&emsp;categoryId|分类id|integer||
|&emsp;&emsp;&emsp;&emsp;id|套餐表id|integer||
|&emsp;&emsp;&emsp;&emsp;image|图片路径|string||
|&emsp;&emsp;&emsp;&emsp;name|套餐名称|string||
|&emsp;&emsp;&emsp;&emsp;price|套餐价格|number||
|&emsp;&emsp;&emsp;&emsp;status|起售状态：0 停售 1 起售|integer||
|&emsp;&emsp;&emsp;&emsp;updateTime|更新时间|string||
|&emsp;&emsp;total|分页前, 满足筛选条件的总记录数|integer(int64)||
|msg|响应信息, 仅在异常时返回|string||


**响应示例**:
```javascript
{
	"code": 1,
	"data": {
		"records": [
			{
				"categoryId": 1,
				"id": 1,
				"image": "https://example.com/setmeal.jpg",
				"name": "商务套餐A",
				"price": 88,
				"status": 1,
				"updateTime": "2026-10-01 10:10:10"
			}
		],
		"total": 100
	},
	"msg": "null"
}
```

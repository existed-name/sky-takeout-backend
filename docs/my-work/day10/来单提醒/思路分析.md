## 来单提醒

### 业务分析

1. 用户下单并且支付成功后、提醒商家
    * 语音播报 + 提示框

### 初步设计

1. 目前学了 WebSocket 跟客户端实时通信, 
    * 可以试试 WebSocket 发送消息、前端提示框展示消息
    * 不知道可不可以发送音频给前端, 
    * 不过可以把音频资源放到前端、前端接收信息就打开音频
2. 封装通信方法供完成支付时调用
    * ...
3. 还是看看教程的设计思路

    ```markdown
    * 通过WebSocket实现管理端页面和服务端保持长连接状态
    * 当客户支付后，调用WebSocket的相关API实现服务端向客户端推送消息
    * 客户端浏览器解析服务端推送的消息，判断是来单提醒还是客户催单，进行相应的消息提示和语音播报
    * 约定服务端发送给客户端浏览器的数据格式为JSON，字段包括：type，orderId，content
      - type 为消息类型，1为来单提醒 2为客户催单
      - orderId 为订单id
      - content 为消息内容
    ```
   
### 实现思路

1. `管理端页面和服务端保持长连接`
    * 管理端前端页面包含 websocket.html 或者嵌入相关请求处理组件
    * 前端连接后端 `localhost:8080/ws/{sid}`
2. 用户完成支付、`sendToAllClients` 发送信息

   ```text
   待接单
   您有一个订单待处理, 订单号: xxx, 请及时处理
   ```
   
3. `约定服务端发送给客户端浏览器的数据格式为JSON`
    * 创建 `WebSocketMessage` 对象, 包装 `type, orderId, content`
    * 把对象内容解析为 json 字符串发给客户端
    * 对应创建 `WebSocketMessageType` 枚举类

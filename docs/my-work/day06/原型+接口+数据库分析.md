## 微信登录功能

### 业务分析

1. 用户进入小程序
2. 小程序检测是否有本地 token / 已登录认证
3. 未登录需要申请获取微信头像、昵称 + 拿到 token
4. 如果是第 1 次使用(新用户) -> 自动注册到数据库


### 相关接口

* 用户登录
  - `/user/login` + POST
  - 入参: 用户登录信息 DTO = 从微信拿到个人信息，头像 + 昵称 + 微信号 + 身份证 + 性别 + 真实姓名
  - 出参: 用户登录信息 VO = token + 用户名


### 数据库表

* `user` 表

```mysql
create table if not exists user (
    id bigint primary key auto_increment comment 'user 表 id', 
    username varchar( 20 ) unique not null  comment '用户名(唯一)', 
    image varchar( 50 ) not null comment '用户头像 URL',
    name varchar( 10 ) not null comment '真实姓名',
    wechat_number varchar( 30 ) unique not null comment '微信号',
    gender varchar( 3 ) comment '性别(可空)',
    id_number varchar( 30 ) unique comment '身份证号(可空)'
)
```



## 商品浏览功能

### 业务分析

1. 登录 → 首页 → 选择分类( 菜品 1 | 套餐 2 )进入到菜品/套餐列表
2. 查询菜品/套餐的所有分类
3. 点击特定分类，进入该分类界面，查询该分类对应的所有菜品/套餐
4. 选择菜品
   * 如果菜品有口味，前端展示 `选择规格`, 否则直接 `➕` 加入购物车
   * 选择规格: 就是选择该菜品口味
   * 点击加号: 加入购物车(记录 id) + 记账
5. 选择套餐: 
    * 直接就是 `➕`
    * 点击后显示该套餐信息 - 组成菜品、份数、描述(配料)、价格


### 相关接口

* 查询菜品/套餐的所有分类
  - GET + `/user/category/list?type=1`
  - 拿到分类的各种子类型
* 查询特定分类包含的所有菜品/套餐
  - GET + `/user/dish/list?categoryId=12`
  - 查询菜品 DishVO = Dish + CategoryName + DishFlavorList(交给前端判断是否有口味)
  - 不过如果分成 2 批来查: 先查 Dish + CategoryName + countDishFlavor，等前端点击 `选择规格` 再来查口味，好像比较分散
  - GET + `/user/setmeal/list?categoryId=13`
* 根据 id 查询套餐
  - GET + `/user/setmeal/{id}`
  - 包含: 根据套餐 id 查询关联菜品名称、份数, 最后组装 SetmealVO
  - 拿到套餐 id、描述、价格……


### 数据库表

* category

  ```mysql
  CREATE TABLE IF NOT EXISTS category (
      id bigint primary key auto_increment comment '分类 id',
      name varchar( 20 ) not null comment '分类名称',
      type tinyint not null comment '分类的类型: 1 菜品分类 2 套餐分类',
      create_time datetime not null default current_timestamp comment '创建时间',
      update_time datetime not null default current_timestamp comment '修改时间',
      create_operator bigint not null comment '创建者 id',
      update_operator bigint not null comment '修改者 id'
  ) comment '菜品/套餐类型表';
  ```

* dish

  ```mysql
  CREATE TABLE IF NOT EXISTS dish (
      id bigint primary key auto_increment comment '菜品 id',
      name varchar( 20 ) not null comment '菜品名称',
      category_id bigint not null comment '菜品所属的分类 id',
      price decimal not null comment '菜品价格',
      create_time datetime not null default current_timestamp comment '创建时间',
      update_time datetime not null default current_timestamp comment '修改时间',
      create_operator bigint not null comment '创建者 id',
      update_operator bigint not null comment '修改者 id',
      INDEX idx_dish_category_id ( category_id )
  ) comment '菜品表';
  ```

* dish_flavor

  ```mysql
  CREATE TABLE IF NOT EXISTS dish_flavor (
      id bigint primary key auto_increment comment '菜品口味 id',
      name varchar( 20 ) not null comment '菜品口味',
      dish_id bigint not null comment '菜品 id',
      INDEX idx_dish_flavor_dish_id ( dish_id )
  ) comment '菜品口味表, 由于修改方式是删除后 Insert、不设置审计字段';
  ```

* setmeal

  ```mysql
  CREATE TABLE IF NOT EXISTS setmeal (
      id bigint primary key auto_increment comment '套餐 id',
      name varchar( 20 ) not null comment '套餐名称',
      category_id bigint not null comment '套餐所属的分类 id',
      price decimal not null comment '套餐价格',
      description varchar( 60 ) comment '套餐描述',
      create_time datetime not null default current_timestamp comment '创建时间',
      update_time datetime not null default current_timestamp comment '修改时间',
      create_operator bigint not null comment '创建者 id',
      update_operator bigint not null comment '修改者 id',
      INDEX idx_setmeal_category_id ( category_id )
  ) comment '套餐表';
  ```

* setmeal_dish

```mysql
CREATE TABLE IF NOT EXISTS setmeal_dish (
    id bigint primary key auto_increment comment '关联关系表 id',
    setmeal_id bigint not null comment '套餐 id',
    dish_id bigint not null comment '关联菜品 id',
    copy int not null comment '关联菜品份数',
    create_time datetime not null default current_timestamp comment '创建时间',
    update_time datetime not null default current_timestamp comment '修改时间',
    create_operator bigint not null comment '创建者 id',
    update_operator bigint not null comment '修改者 id',
    INDEX idx_setmeal_dish_setmeal_id ( setmeal_id )
) comment '套餐-菜品关联关系表';
```

## 地址簿管理

### 业务分析
1. 用户进入个人中心，进入地址管理界面
2. 展示用户的所有收货地址
3. 可以勾选某地址的 `设为默认地址`, 只能有 1 个默认地址
4. 可以点击底部新增收货地址
    * 填写信息: 
      - 联系人姓名
      - 性别(先生/女士，默认先生)
      - 手机号
      - 收货地址
      - 标签(公司/学校/家)
    * 然后保存地址
5. 点击地址，进入编辑界面
    * 编辑信息
    * 点击保存地址
    * 或者删除地址


### 相关接口
1. 展示所有收货地址
    * GET + `/user/address/list`
    * List< AddressVO > = id + name + gender + phoneNumber + address + tag + isDefault
2. 设为默认地址
    * PUT + `/user/address/default/{id}`
    * 注意先把已有的默认地址 isDefault 改成 false
3. 新增收货地址
    * POST + `/user/address`
    * AddressDTO = name + gender + phoneNumber + address + tag + isDefault(默认 false)
4. 修改收货地址
    * PUT + `/user/address`
    * AddressDTO = id + name + gender + phoneNumber + address + tag + isDefault
5. 删除地址
    * DELETE + `/user/address/{id}`


### 数据库表
1. address

```mysql
create table if not exists address (
    id bigint primary key auto_increment comment '收货地址主键 id',
    user_id bigint not null comment '用户 id',
    name varchar( 20 ) not null comment '收货人姓名',
    gender varchar( 3 ) not null default '先生' comment '性别',
    address varchar( 60 ) not null comment '收货地址',
    tag varchar( 10 ) default null comment '地址标签: 家、公司、学校, 我觉得可以为空',
    is_default boolean default false comment '是否是默认地址',
    create_time datetime not null default current_timestamp comment '创建时间',
    INDEX idx_address_is_default is_default,
    INDEX idx_address_user_id user_id
) comment '收货地址表';
```

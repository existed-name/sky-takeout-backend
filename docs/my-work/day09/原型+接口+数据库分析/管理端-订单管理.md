## 管理端-订单管理

### 业务分析

1. 点击进入 `订单关联` 界面
2. 界面上方可选订单分类: 
   * `全部订单`、`待接单(数量)`、`待派送(数量)`、`派送中(数量)`、`已完成`、`已取消`
   * 都会分页展示，每页条数 = 6
3. 条件查询: 
    * 订单号
    * 手机号
    * 下单时间范围
    * 查询/重置按钮
    * `全部订单` 展示内容: 
      - 订单号、订单状态、用户名、手机号、具体地址、下单时间、实收金额
      - 操作: 查看、根据订单状态显示接单/拒单 + 派送/取消 + 完成 + 退单
    * `待接单` 展示内容
      - 订单号、订单菜品、具体地址、预计送达时间、实收金额、备注
      - 订单菜品 = `菜品名 * 菜品数量` 中文分号隔开
      - 操作：接单、拒单、查看
    * `待派送` 展示内容
       - 订单号、订单菜品、具体地址、预计送达时间、备注、餐具数量
       - 订单菜品 = `菜品名 * 菜品数量` 中文分号隔开
       - 操作：派送、取消、查看
   * `派送中` 展示内容
      - 订单号、订单菜品、具体地址、预计送达时间、备注
      - 订单菜品 = `菜品名 * 菜品数量` 中文分号隔开
      - 操作：完成、取消、查看    
   * `已完成` 展示内容
      - 订单号、用户名、手机号、具体地址、送达时间、实收金额、备注
      - 操作：退单、查看
   * `已取消` 展示内容
      - 订单号、用户名、手机号、具体地址、下单时间、取消时间、取消原因
      - 操作：查看


### 相关接口

1. 条件分页查询
   * GET + `/admin/orders`
   * AdminOrderPageQueryDTO = 
     - page(必填) + pageSize(必填) + status(必填) + 
     - orderNumber + phone + orderTimeBegin + orderTimeEnd
   * AdminOrderPageVO = 
     - BaseColumn = id + orderNumber + address
     - 全部订单: 
       * BaseColumn + 
       * userName + phone + orderTime + amount
     - 待接单/待派送/派送中
       * BaseColumn
       * goods 菜品展示 = "dishName * number", "setmealName * number", 但是 dishFlavor 怎么算
       * estimatedDeliveryTime
       * remark
     - 已完成
       * BaseColumn
       * deliveryTime
     - 已取消
       * BaseColumn
       * orderTime + cancelTime + cancelReason
2. 统计订单数量
    * 接口路径 GET `/admin/orders/count?status=xx`
    * 请求数据: Integer 订单状态
    * 响应数据: Long 数量, 对应 id 为 Long
3. 接单
    * 对 `待接单` 的订单修改订单状态
    * 依然会展示订单详情, 且包括预计送达时间

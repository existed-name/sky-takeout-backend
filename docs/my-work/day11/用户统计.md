## 原型分析

1. 横坐标: 日期 LocalDate
2. 纵坐标: 用户量
3. 2 条线
    * 总用户量: 直接统计每天注册/创建的用户账户数量
    * 用户增量: 今天相对昨天新增多少用户

## 接口设计

1. 接口路径
    * GET + `/admin/report/user-statistics`
2. 前端入参
    * begin , end
3. 后端输出
    * `UserStatisticsReportVO` = `List< UserCountItemVO >` + `List< UserGrowthItemVO >`
    * UserCountItemVO = LocalDate date + Long count
    * UserGrowthItemVO = LocalDate date + Long growth

## 实现思路

1. 主要靠 sql 统计, 查 2 次数据库
2. 统计每天总用户量
    * 这里的业务没有注销、软删除之类的说法, 而且注册就会创建账号, 直接统计全部用户就行
    * 不过有时间范围, 但其实语义是从最开始 ~ 某个时间点的总用户
    * 所以如果不考虑性能, 可以直接循环查库 `WHERE create_time <= #{deadline}`
    * 那么既然循环、那其实是枚举 → CASE WHEN , 但是不能枚举 WHERE 条件、只能枚举前面增改查的字段
    * 可不可以在数据层给他复制成多个表, 每个表对应一个截止时间点, 查出来汇总?
3. 统计每天用户增量
    * 每天比昨天多了多少
    * 先看单次调用的写法
      1. 单独写一个只查某一天的数据, 查出昨天、今天的用户量, service 做差
      2. 直接 sql 内部做差

   ```mysql
   select ( yesterday.count - today.count ) AS count
   from
      ( select count( * ) AS count
      from orders
      # 这里 yesterday 可以替换成 today 调函数 - 1 天
      where date( create_time ) = #{yesterday} ) AS yesterday,
      ( select count( * ) AS count
      from orders
      where date( create_time ) = #{today} ) AS today,
   ```

4. 但是我感觉我思路狭窄了
    * 根据经验 `group by date`, 但是我想分组会跟这里的统计冲突
    * 但是如果确实考虑分组 → 其实只是把大表格内部的小单元格合并, 并不会改变太多核心结构

   ```mysql
   select create_date, count( * ) AS count
   from users
   group by date( create_time ) AS create_date
   ```
   
    * 这个算新表格 temp_users, 那么就有了每天日期 + 这天新增的用户
    * 那么就找到了出路
    * 直接补一个 `where` 筛选时间范围, 就可以拿到范围内每天新增的用户量
    * 如果要求总人数, 那就筛选截止时间前的数据, 然后 sum
5. 总结 sql
    * 核心是上面那个分组合并每一天的数据

   ```mysql
   select create_date, count( * ) AS count
   from users
   group by date( create_time ) AS create_date
   ```

    * 找每天新增用户量

   ```mysql
   select create_date AS date, count AS growth
   from (
      select create_date, count( * ) AS count
      from users
      group by date( create_time ) AS create_date 
   ) AS temp_users
   where #{begin} &lt;= create_date and create_date &lt;= #{end}
   ```
   
    * 每天的总用户量, 
      - 全部查出来作前缀和太大太长, 
      - 用 sql 好像只能指定单一范围, 不能指定多范围

   ```mysql
   select create_date AS date, sum( count ) AS growth
   from (
      select create_date, count( * ) AS count
      from users
      group by date( create_time ) AS create_date 
   ) AS temp_users
   where create_date &lt;= #{deadline}
   ```
   
      - 难道还是要循环调用单次查询

   ```mysql
   SELECT create_time AS date, sum( * ) AS total
   FROM user
   WHER create_time &lt;= #{deadline}
   ```

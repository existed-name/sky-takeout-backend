## 原型分析

1. 横坐标 日期 date
2. 纵坐标 订单数量
3. 查询时间范围内, 每天的订单总量、有效订单数量（已完成订单）
4. 还需要查询所有的订单数量、有效订单、完成率

## 接口设计

1. 前端入参
    * begin, end
2. 后端出参
    * `OrderReportVO` 
      - Long total
      - Long validCount
      - Double completionRate
      - List< OrderCountItemVO >
      - List< OrderValidCountItemVO >
    * OrderCountItemVO / OrderValidCountItemVO
      - LocalDate date
      - Long count

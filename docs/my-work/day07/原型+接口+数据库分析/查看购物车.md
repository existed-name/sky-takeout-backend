## 查看购物车

### 业务分析

1. 用户点击进入购物车，展示选购的菜品、套餐
    * 可点击 `➕` `➖` 修改份数
    * 并且菜品单独注明 `口味`(规格)
    * 展示总金额
    * 结算
    * 可点击清空购物车
   
### 相关接口

1. 查看购物车
    * GET + `/user/shoppingCart/list`
    * ShoppingCartVO = List< ShoppingCartDishVO > + List< ShoppingCartSetmealVO > + totalAmount(总价)
      - ShoppingCartDishVO = name + image + copies + price( 单价 )
      - ShoppingCartSetmealVO = name + image + copies + price
    
2. 点击 `➕` 新增购物车内容
    * POST + `/user/shoppingCart`
    * ShoppingCartDTO = dishId + dishFlavor // 菜品种类( id、flavor 定位)
                        + setmealId // 套餐种类, 套餐/菜品 2 选 1，因为每次点击只能是 1 种

3. 点击 `➖` 减少内容
    * PUT + `/user/shoppingCart`
    * ShoppingCartDTO = dishId + dishFlavor + setmealId
    * number 份数减一，如果减为 0，就把这条数据删掉
    * 所以我不确定是 PUT 修改还是 DELETE


### 数据库表

1. shopping_cart

```mysql
create table if not exists shopping_cart (
    id bigint primary key auto_increment comment '主键',
    user_id bigint not null comment '用户 id',
    dish_id bigint default null comment '菜品 id，与套餐 id 二选一',
    dish_flavor varchar( 20 ) default null comment '菜品口味',
    setmeal_id bigint default null comment '套餐 id，与菜品 id 二选一',
    create_time datetime not null default current_timestamp comment '创建时间',
    INDEX idx_shopping_cart_usesr_id user_id
) comment '用户购物车表';
```

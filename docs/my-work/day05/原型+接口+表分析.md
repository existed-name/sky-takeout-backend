# 原型分析

* 营业状态展示
  - 营业中: 用户可下单
  - 打烊: 用户不可下单
* 营业状态按钮
  - 点击进入修改状态界面
  - 默认正在营业

    
# 相关接口

* 查询营业状态
  - `/admin/openstatus` + GET
* 修改营业状态
  - `/admin/openstatus/{status}` + PUT


# 数据库表

* 好像没必要为营业状态单独设置 1 个表
* 比如直接用 1 个全局变量替代，对这个全局变量增删改查
* 再结合 day05 内容，也就是存 Redis 里面
* 所以只需要 `redisKey = openstatus` -> `filed = 1 / 0`
* 为啥不用全局变量，直接用它存状态，要用数据库?? -- 因为重启项目就刷新了，但是要数据持久化，还是要回到数据库(Redis)
* 然后不设置有效时间、保持持续有效

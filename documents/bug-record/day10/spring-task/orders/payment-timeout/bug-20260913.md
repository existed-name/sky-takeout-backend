2. 检查语法
    * `com.sky.mapper.OrderMapper.updateBatchByIds`
    * 起初以为是 `<set>` 标签里面的各个 `<if>` 不需要补充逗号、交给 `<set>` 标签自己处理逗号, 但是感觉不是主要原因

    ```xml
        <!--
        批量更新订单
        -->
        <update id="updateBatchByIds">
            <foreach collection="orders" item="order" separator=";">
                UPDATE orders
                <set>
                    <if test="order.status != null">
                        status = #{order.status},
                    </if>
                    ...
                    <if test="order.deliveryTime != null">
                        delivery_time = #{order.deliveryTime}
                    </if>
                </set>
                WHERE id = #{order.id}
            </foreach>
        </update>
    ```

3. 问 ai => mysql 默认不支持多条语句拼在一起
    * 1 个分号算 1 条语句, 我这里多条 update 拼在一起、mysql 只认第 1 条、之后的就报错
    * 对应的开关是给 jdbc url 补充 `allowMultiQueries=true` 允许一次性多条语句
      - 但 ai 说有注入和性能风险、不推荐
4. 解决方法
   1. 改用 `CASE WHEN` 不同 id 的订单分别设置自己的信息
   2. 由于我这里刚好都设置相同的字段值、所以可以直接 `where id in( ... )` 一起设置
   3. `ExecutorType.BATCH` 感觉比较高级
   4. service 循环调用 updateById( 就是因为不想多次操作数据库、才想的尽量一次性到位 )
   5. ...
5. 看 `CASE WHEN` 写起来也比较复杂、还是先循环 update, 之后优化

## Edge 打开 websocket.html 不能往服务端发送信息

1. 对于[websocket 演示界面](/sky-server/src/main/java/com/sky/websocket/websocket.html)
    * 如果我是在文件资源管理器打开它
      - Edge 地址栏会显示 `file:///绝对路径`, 
      - 点击 `发送消息` 按键( `com/sky/websocket/websocket.html:9` )后端是接收不到客户端消息的
      - F12 Networks 里面只看到 `websocket.html`
    * 如果是从 IDEA 进入 Edge
      - 地址栏 `http://localhost:63342/UserController.java/sky-server/com/sky/websocket/websocket.html?_ijt=vumoi12rm1pvd51f9mi1bi4u34&_ij_reload=RELOAD_ON_SAVE`
      - 后端能够接收到 html 发送的消息
      - `2026-09-14 08:05:33.597 DEBUG 49748 --- [nio-8080-exec-2] com.sky.websocket.WebSocketServer        : WebSocket 收到客户端信息, sid = nr0lj0a5psr, message = 你好`
      - F12 Networks 可以看到 4 个请求
        - `ws://localhost:63342/jb-server-page?reloadMode=RELOAD_ON_SAVE&referrer=%2FUserController.java%2Fsky-server%2Fcom%2Fsky%2Fwebsocket%2Fwebsocket.html`
          * 这个是 IDEA 自带的热重载通道
        - `http://localhost:63342/UserController.java/sky-server/com/sky/websocket/websocket.html?_ijt=vumoi12rm1pvd51f9mi1bi4u34&_ij_reload=RELOAD_ON_SAVE`
          * 请求 websocket.html 页面
        - `ws://localhost:8080/ws/nr0lj0a5psr`
          * 这个才是 `/ws/{sid}` 请求路径
        - `http://localhost:63342/favicon.ico`
          * 浏览器自动发送
        - 不过发送信息、关闭连接不会有单独的请求
2. 尝试移到 `sky-server/src/main/resources/static/websocket.html`
    * 然后访问 `http://localhost:8080/websocket.html` 
    * 不过页面不存在、后端警告 `No mapping for GET /websocket.html`
3. 总结
    * 可能需要像前端一样打包放在 nginx 之类的访问
    * 还是老老实实用 IDEA 打开 html

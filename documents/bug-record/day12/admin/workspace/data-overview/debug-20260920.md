## 编译时, 链表 getFirst 报错找不到符号

1. 问题现象
    * `com.sky.service.impl.WorkspaceServiceImpl.getDataOverviewByDate`
    * 每个 List 调用 getFirst 方法的地方都报错找不到符号
2. 报错信息

    ```text
    java: 找不到符号
      符号:   方法 getFirst()
      位置: 类型为java.util.List<com.sky.vo.report.UserGrowthItemVO>的变量 userGrowthItemVOList
    ```

3. 代码

    ```java
    /*
        1. 新增用户量
    */
    List< UserGrowthItemVO > userGrowthItemVOList = userMapper.countGroupByDate( begin, endExclusive );
    UserGrowthItemVO userGrowthItemVO = userGrowthItemVOList.getFirst();
    // 由于只查当天数据, 只会查出 1 个数据对象或者查出 null
    long newUsers = userGrowthItemVO == null ? 0L : userGrowthItemVO.getGrowth();
    ```

4. 初步思考
    * 首先可不可能是 List 接口、ArrayList 实现类的差异？
      - 但 mybatis 通常运行时返回具体的实现类
    * 再看是不是我 getFirst 用错了
    * 于是进去看源码

    ```java
    // ArrayList 也基本一样
    default E getFirst() {
        if (this.isEmpty()) {
            throw new NoSuchElementException();
        } else {
            return this.get(0);
        }
    }
    ```
   
    * 首先我这个 getFirst + 判空可能用错了
      - 如果不存在第 1 个元素、getFirst 会直接抛异常
      - 不过 mybatis 查询列表的时候, 不一定跳过 null 数据, 还是可能包装成列表元素/ add
      - 所以拿到的列表也可能存在 null 元素
5. 先修改逻辑
    * isEmpty 判断链表是否包含数据
    * 再 getFirst 判断拿到的东西是否为空
    * 不过还是会报错找不到符号
6. 问 AI
    * 666，Java21 才引入的 getFirst...
    * 好吧暂时 get( 0 )


## 计算数据异常 = 0

1. 问题现象
    * 响应数据中, 订单完成率、营业额、客单价为 0 不对头

        ```json
        "data": {
            "newUsers": 0,
            "validOrderCount": 2,
            "orderCompletionRate": 0.0,
            "turnover": 0,
            "unitPrice": 0.00
        }
        ```
      
    * 输出 VO 和局部变量的信息

        ```text
        dataOverviewVO = DataOverviewVO(
            newUsers=0, 
            validOrderCount=2, 
            orderCompletionRate=0.0, 
            turnover=0, 
            unitPrice=0.00
        ), orderCount = 4
        ```
      
2. 首先排查 orderCompletionRate 为什么是 0
    * 明明应该 = validOrderCount / orderCount = 0.5
    * 说明是计算时 / 传参出了问题
    * 原来是抽取公共计算方法时漏写了计算逻辑, 直接把完成率赋值 0、忘了计算
3. 再看为什么 turnover = 0
    * 一路找到 SQL

    ```mysql
    SELECT date( checkout_time ) AS date, sum( amount ) AS turnover
    FROM orders
    WHERE status = #{status} AND
        #{begin} &lt;= checkout_time AND
        checkout_time &lt; #{endExclusive}
    GROUP BY date
    # u1s1 这里该用 date( checkout_time ), 标准 SQL 可能不支持 group by + 别名
    ```
   
    * 原来是我把结账时间作为计算营业额依据、而不是下单时间
    * 不过语义上也没问题, 肯定结账的时候才收到钱、算营业额
    * 并且定时任务机制也保证一段时间不付款就取消订单
    * 所以其实是我设置的数据有问题，结账时间、下单时间没设置在同一天
4. 把订单的下单时间、结账时间改为同一天后
    * 解决 turnover、unitPrice = 0 的问题

* 问 AI: 
  - `@MapKey` 必须确保 Map 的 Value 可以通过 getter 拿到 key
  - 也就是 `@MapKey( "status" )`, 必须能够通过 Value.getStatus 拿到 status
  - 但是我的 `Map< Integer, Long >` Long 类型没有 getStatus 方法, 所以报错
  - 解决方法是回归原始的 `List< Map< Object, Object > >` 
  - 或者把 Value 包装成对象、能够使用 getStatus 方法

  ```java
      @Select( """
              SELECT status, count( * ) AS count
              FROM orders
              GROUP BY status
              """ )
      @MapKey( "status" )
      Map< Integer, OrderStatusCount > countGroupByStatus();
  ```

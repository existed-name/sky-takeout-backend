## 不传 RequestParam 报错未知系统异常

1. ApiFox 测试, 不带 status 订单状态, 报错

    ```text
    2026-08-23 10:54:59.754 ERROR 52984 --- [nio-8080-exec-6] com.sky.handler.GlobalExceptionHandler   : 未知系统异常
    
    org.springframework.web.bind.MissingServletRequestParameterException: Required request parameter 'status' for method parameter type Integer is not present
    ```

2. 接口情况

    ```java
        @ApiOperation( "统计某种状态的订单数量" )
        @GetMapping( "/statistics" )
        public Result< Long > count(
                @RequestParam( "status" )
                @NotNull( message = "订单状态不能为空" )
                Integer status
        ){}
    ```

3. 带上 status 参数但是不赋值

   ```text
   2026-08-23 16:21:56.911 ERROR 52984 --- [nio-8080-exec-4] com.sky.handler.GlobalExceptionHandler   : 未知系统异常
   
   org.springframework.web.bind.MissingServletRequestParameterException: Required request parameter 'status' for method parameter type Integer is present but converted to null
   ```

4. 显示赋值就没问题
5. 不过也爆出了类型转换错误

   ```text
   2026-08-23 16:26:00.373 ERROR 52984 --- [nio-8080-exec-3] com.sky.handler.GlobalExceptionHandler   : 未知系统异常
   
   org.springframework.web.method.annotation.MethodArgumentTypeMismatchException: Failed to convert value of type 'java.lang.String' to required type 'java.lang.Integer'; nested exception is java.lang.NumberFormatException: For input string: "1.5"
   ```

6. 解决
    * 补充对应的异常到全局异常处理器
    * 注意 `@RequestParam` 默认 `required = true` 判空, 不需要 `@NotNull`

   ```java
       /**
        * 捕获不传 RequestParam 或者不给 RequestParam 赋值抛出的请求参数缺少异常
        */
       @ExceptionHandler( MissingServletRequestParameterException.class )
       public Result< String > handleMissingRequestParamException( MissingServletRequestParameterException ex ){
           String parameterName = ex.getParameterName();
           return Result.error( String.format( "请求参数 %s 不能为空", parameterName ) );
       }
   
       /**
        * 捕获前端传入参数绑定到后端字段抛出的数据类型转换错误
        */
       @ExceptionHandler( MethodArgumentTypeMismatchException.class )
       public Result< String > handleTypeMismatchException( MethodArgumentTypeMismatchException ex ){
           return Result.error( "参数类型转换错误, 请检查参数数据类型是否满足要求" );
       }
   ```

7. 并且还要注意 `MethodArgumentTypeMismatchException` 有多个包、导入对应的包

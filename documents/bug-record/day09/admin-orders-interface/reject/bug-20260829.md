## 明明是 PutMapping、请求方法也是 Put, 但是报错请求方法不匹配

1. 接口情况

    ```java
        @ApiOperation( "拒绝订单" )
        @PutMapping( "/{id}/reject" )
        public Result< Void > reject(
                @PathVariable( name = "id", required = true )
                @NotNull( message = "订单 id 不能为空" )
                @Positive( message = "订单 id 必须是正整数" )
                Long id,
                @RequestBody @Valid
                @NotNull( message = "订单拒绝信息不能为空" )
                OrdersRejectionDTO orderRejectionDTO
        ){}
    ```

2. 请求数据
    * PUT `/admin/orders/{id}/reject` id 置空、不赋值
    * dto 正常

    ```json
    {
        "rejectionReason": "quis sed"
    }
    ```

3. 报错信息
    * `2026-08-29 20:11:19.087 ERROR 27988 --- [nio-8080-exec-9] com.sky.handler.GlobalExceptionHandler   : HTTP 请求方法不匹配: Request method 'PUT' not supported`
4. 但是如果 id 显式赋值, 包括字符串、浮点数, 都可以正常运行
5. 怀疑是隐藏了异常 → 子类被父类异常捕获

    ```java
        public Result< String > handleHttpRequestMethodNotSupportedException( HttpRequestMethodNotSupportedException e ){
            // log.warn( "HTTP 请求方法不匹配: {}", e.getMessage() );
            // 改成 ↓ 直接展示
            log.warn( "", e );
        }
    ```

6. 然而依然就是 `HttpRequestMethodNotSupportedException`

    ```text
    org.springframework.web.HttpRequestMethodNotSupportedException: Request method 'PUT' not supported
        at org.springframework.web.servlet.mvc.method.RequestMappingInfoHandlerMapping.handleNoMatch(RequestMappingInfoHandlerMapping.java:253) ~[spring-webmvc-5.3.22.jar:5.3.22]
        at org.springframework.web.servlet.handler.AbstractHandlerMethodMapping.lookupHandlerMethod(AbstractHandlerMethodMapping.java:442) ~[spring-webmvc-5.3.22.jar:5.3.22]

        at org.springframework.web.servlet.mvc.method.RequestMappingInfoHandlerMapping.getHandlerInternal(RequestMappingInfoHandlerMapping.java:67) ~[spring-webmvc-5.3.22.jar:5.3.22]
    ```

7. 如果拿着 PUT `/admin/orders/reject` + RequestBody 访问接口, 同样的 `HttpRequestMethodNotSupportedException`

   ```text
   org.springframework.web.HttpRequestMethodNotSupportedException: Request method 'PUT' not supported
   ```

8. 如果 GET/POST/DELETE `/admin/orders/{id}/reject` + RequestBody, 就会 `404 NOT FOUND No mapping for POST /admin/orders/具体的id数值/rejection`
9. 总结问题情况
    * PUT `/admin/orders/{id}/reject` 只在 id 不赋值时出现 `HttpRequestMethodNotSupportedException`
    * 并且虽然我显式要求 id 非空 `@PathVariable( name = "id", required = true ) @NotNull( message = "订单 id 不能为空" )`, 但实际并没有拦截到
    * GET/POST/DELETE`/admin/orders/{id}/reject` 不管 id 有没有赋值, 都会 `HttpRequestMethodNotSupportedException`
    * 另外一个奇特现象 GET `/admin/orders//reject` 或者 `/admin/orders/reject` 不会提示请求方法不支持、而是`参数类型转换错误` `MethodArgumentTypeMismatchException`
    * 补充兜底处理, 发现 PUT `/admin/orders//reject` 或者 `/admin/orders/reject` 可以命中他

   ```java
       @PutMapping( "/reject" )
       public Result< String > handleMissingId(){
           return Result.error( "订单 id 不能为空" );
       }
   ```

10. 原因
    * 问 GLM-5.3-Flash 问出来了...
    * {id} 为空, 原路径自动缩写为 `/admin/orders/reject`, 
    * 匹配路径的时候把 `reject` 字符串当成了 id 处理, 
    * 而已有的 `/admin/orders/{id}` 不支持 PUT 所以报错
